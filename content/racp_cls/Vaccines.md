### Overview
Vaccination is a means by which to induce [[active immunity]] against a given infective agent:
1. The vaccine [[antigen]] is introduced 
2. Antigen presenting cells identify and phagocytose the vaccine antigens 
3. The APCs express antigens via MHCII molecules to induce an immune response via CD4+ (T-helper cells) and CD8+ (effector T and memory T cells), the former of which go to to help the induction of B-cell mediated humoral immunity  

Classes of vaccines inclue live vaccines, [[live attenuated vaccines]], and [[inactivated vaccines]]. One other important distinction is between polysaccharide and conjugated vaccines, as many bacterial pathogens have polysaccharide outer layers.

![](Vaccines/image.png)

The advantages of [[conugated vaccines]]:
- The linkage of polysaccharide to carrier protein allows better presentation to MHCII _without_ T-cell recognition of polysaccharide
- This also allows for costimulatory signalling to T-cells, promoting long-lasting memory T-cells
- Superior immunogenic ability in children
- Superior T-cell mediated immune memory
- Elicitation of avidity maturation
- Long-lasting

The prototypic conjugated vaccines are those against the pneumococcus, which typically consist of a polysaccharide antigen conjugated to a diphtheria carrier protein. The current standard is a 13-valent vaccine. 

#### Adjuvants
Adjuvants are substances that non-specifically enhance the response to an antigen, which are injected simultaneously with the vaccine antigen. These were to trigger TLRs and activate APCs.

| Live attenuated shingles (Zostavax) | Inactivated polio                                  |

|                                     | Salmonella typhi                                   |

|                                     | Conjugated pneumococcal                            |
|                                     | Recombinant adjuvanted shingles vaccine (Shingrix) |
|                                     | Monkeypox (live but replication defective)         |

Contraindications to live vaccines include:
- Age <6m
- CD4+ count <200
- Thymus disorders
- Other severe immunodeficiencies
- Concurrent use of immunosuppressants (incl. pred. >20mg/d)

Most live vaccines can be given simultaneously, but if not, the recommended interval is 4w.

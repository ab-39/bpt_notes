### Overview
| Component        | Reference Range | Interpretation                                               |
|------------------|-----------------|--------------------------------------------------------------|
| Haemoglobin      | 130-150g/L      | Measurement of red blood cell mass                           |
| Haematocrit      | 0.3-0.5         | Haemoglobin as a proportion of the blood<br>Does not really provide much additional information over and above the Hb, except as a target for venesection in polycythaemia |
| Mean Cell Volume | 80-100fL        | Measurement of the size of red blood cells                   |
| Platelets        | 150-450/nL      |                                                              |
| Red Cell Count   | 4.5-6.5/pL      | Absolute number of red cells                                 |
| White Cell Count |                 |                                                              |
| Neutrophils      | 1.7-7/nL        |                                                              |
| Lymphocytes      |                 |                                                              |
| Monocytes        |                 |                                                              |
| Eosinophils      |                 |                                                              |

#bpt/haematology

### Overview
| Cell Class            | Surface Markers                        |
|-----------------------|----------------------------------------|
| Stem cells            | CD34                                   |
| **All** leucocytes    | CD45                                   |
| Immature thymic cells | TDT, CD3, CD4, CD8                     |
| T-cells               | TCR, CD2, CD3, CD4, CD8, CD40L         |
| B-cells               | CD19, CD20, MHC II, sIGM/G, CD35, CD21 |
| Macrophages           | MHC II, CD35, CD32, CD11b              |
| Dendritic cells       | MHC II, CD1a, CD11                     |
| Neutrophils           | CD35, FcR, Ly6C                        |
| Mast cells            | FcR for IgE                            |

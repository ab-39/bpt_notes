# Evaluation of Pleural Fluid
#bpt/respiratory #bpt/racp_cls
- - -
## Stepwise Approach:
So… you’ve drained the [[pleural effusion]] - now what?
### Gross Inspection:
1. Colour:
   - Pale yellow/straw -> transudate
   - Red -> blood, malignancy
   - White/milky -> chylothorax, cholesterol effusion 
   - Black -> rare infections or melanoma
   - Dark green -> bilothorax/bilirubin
2. Consistency:
   - Pus -> infection
   - Viscous -> mesothelioma
   - Debris -> rheumatoid pleurisy
   - ”Anchovy paste” -> amoebic liver abscess
3. Odour:
   - Putrid -> anaerobic effusion
   - Ammonia -> urinothorax 

### Pleural Fluid Analysis:
1. Routine Tests:
   - Cell count and differential
   - Total protein and LDH (for [[Light criteria]])
   - Glucose
   - Culture and Gram stain
   - Cytology
2. Specialised Biomarkers:
   - pH -> <7.2 -> parapneumonic effusion
   - AFB smear/adenosine deaminase -> TB effusion
   - flow cytometry -> lymphoma, multiple myeloma 
   - amylase -> oesophageal rupture or pancreatitis
   - lipids -> [[chylothorax]]
   - haematocrit (+) -> haemothorax (>0.5 serum level)
   - creatinine (+)  -> urinothorax (>1.7 serum level)
   - bilirubin (+) -> bilothorax  (>1.0 serum level)
   - β2 transferrin -> CSF leakage
3. Serum Tests as above

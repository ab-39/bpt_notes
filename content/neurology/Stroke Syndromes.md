### Overview

| Affected Artery           | Eponym                         | Clinical Features                                            |
|---------------------------|--------------------------------|--------------------------------------------------------------|
| MCA                       |                                | Contralateral hemiplegia, hemianaesthesia, and homonymous hemianopia<br>Ipsilateral Lateral gaze palsy (towards the lesion/away from the weakness)<br><br>Left MCA: can also have aphasia <br><br>Right MCA: neglect |
| Superior M2               |                                | Similar to MCA but leg sparing and with an inferior quadrantanopia<br><br>Broca’s aphasia (expressive/nonfluent) |
| Inferior M2               |                                | Similar to MCA but with a superior quadrantanopia<br><br>Wernicke’s aphasia (receptive/fluent) |
| ACÁ                       |                                | Contralateral sensorimotor loss worse in the legs<br><br>Urinary incontinence <br><br>Frontal signs - lack of spontaneity, abulia<br><br>Alien hand syndrome |
| Anterior choroidal artery |                                | Contralateral hemiplegia, hemianaesthesia, and homonymous hemianopia |
| P1 (PCA)                  |                                | Midbrain, subthalamic, and thalamic signs                    |
| P2 (PCA)                  |                                | Cortical temporal and occipital signs                        |
| V4                        | Wallenberg (lateral medullary) | Vertigo, ipsilateral facial numbness, contralateral limb numbness, diplopia, dysarthria, dysphagia, ipsilateral Horner syndrome (ptosis, miosis, anhidrosis) |
| Pons/basilar artery       |                                | “Locked in” syndrome; depending on extent may even involve conscious state  |

Classic lacunar stroke syndromes and their correlates:
- Pure motor = posterior limb of the internal capsule 
- Ataxic hemiparesis = anterior limb of the internal capsule, basilar pons, corona radiata 
- “dysarthria/clumsy hand syndrome”
- Pure sensory = thalamus 
- Sensorimotor = thalamus and internal capsule

### Partial Horner Syndrome
![](Stroke%20Syndromes/Sympatheticinputtopupil.jpg.jpeg)
Note that the third-order sudomotor branches of the autonomic system branch that supply the face branch off from those that control pupillomotor function, eyelid movement, and supply the forehead at the carotid bifurcation. Thus while a full Horner’s syndrome may localise to before this point, a partial Horner’s syndrome _could_ suggest an ICA dissection and needs to be investigated appropriately.

# Acid-Base Disorders
#bpt/physiology

All revolves around the fact that water and carbon dioxide are in equilibrium with hydrogen and bicarbonate via the intermediary of carbonic acid. 

Four main classes:
1. [[physiology/Metabolic Acidosis|Metabolic Acidosis]] - pCO2 drops to buffer rising H+ -> they both go in opposite directions
2. [[physiology/Metabolic Alkalosis|Metabolic Alkalosis]] - pCO2 rises to buffer falling H+ -> they both go in opposite directions 
3. [[Respiratory Acidosis]] - HCO3- rises to buffer rising H+ -> they both go in the same direction
4. [[respiratory/Respiratory Alkalosis|Respiratory Alkalosis]] - HCO3- drops to buffer falling H+ -> they both go in the same direction

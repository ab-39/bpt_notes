# Approach to the Examination of the Hands
#bpt/clinical
- - -
> [!TIP]  - Talley and O’Connor’s “Hand Dance”
> 1. Inspect with the hands **pronated**
> 2. Inspect with the hands **supinated**
> 3. Inspect with the hands in a **fist**, and then **opened**
> 4. Inspect with the hands folded, in a **prayer** sign 
> 5. Inspect with the hands folded the other way, check for **Phalen’s sign** 
> 6. Inspect the elbows with the hands **behind the head**
> 7. Inspect with the arms **abducted to 90º** 
> 8. Inspect with the hands **behind the back**

### Key Differentials in the Hand Exam
| Differential                                       | Key Findings                                                 | Other Distinctive Findings                                   |
|----------------------------------------------------|--------------------------------------------------------------|--------------------------------------------------------------|
| [[Rheumatoid Arthritis]]                           | Symmetrical<br>Deforming<br>Polyarthropathy                  | Wrist = radial deviation<br>MCPs = ulnar deviation, volar subluxation<br>Fingers = swan-necking, Boutonniere deformity<br>PIP = Bouchard nodes<br>Thumb = Z-deformity |
| [[Psoriatic Arthritis]]                            | Evidence of psoriasis - extensor tendons, elbows, scalp, periumbilicus, nail pitting, onycholysis. dactylitis <br> | Five patterns:<br>1. Asymmetrical oligoarthropathy<br>2. Rheumatoid pattern<br>3. DIP arthritis + nails<br>4. Arthritis obliterans<br>5. Axial spondylitis |
| Crystal Arthropathies                              | Gout = usually first MTP +/- tophi<br>CPPD = usually knees or wrists<br>Hydroxyapatite deposition disease = calcific tendonitis |                                                              |
| [[Osteoarthritis]]                                 | Can affect any joint, but tends to affect digits 1-5, with:<br>- PIP = Bouchard nodes<br>- DIP = Heberden nodes <br>- squaring of the base of the thumb |                                                              |
| [[Haemochromatosis]]                               | Consider if 2nd and 3rd digits (particularly MCPs) are the most involved | Go to abdomen next                                           |
| [[Systemic Sclerosis]]                             | Limited = “gloves and stockings” + face <br>Diffuse = involvement of upper arms or chest<br>Looking for:<br>Digital ulceration<br>Calcinosis<br>Telangiectasis |                                                              |
| [[rheumatology/Systemic Lupus Erythematosus|Systemic Lupus Erythematosus]]                   | Jaccoud arthropathy = correctable deformiies                 |                                                              |
| [[rheumatology/Inflammatory Myopathies|Inflammatory Myopathies]] - e.g. dermatomyositis | Generally an adjunct to an ILD case = looking for skin findings |                                                              |

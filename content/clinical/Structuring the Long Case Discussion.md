# Structuring the Long Case Discussion
#bpt/clinical
- - -
### Overall Points
- Keep it big picture
- Think about a tree:
  - Start with the **trunk** -> a big picture statement that summarises the _impact_ that the issue has on the patient
  - Next, move to the **branches** -> individual, “sub-issues” that contribute to the main issue 
    - Like real branches, these can intertwine with one another
  - Finally, end on the **leaves** -> specific management points, _tailored to the patient’s situation_ 
    - Do **NOT** start with the leaves

# Severity of Diabetic Foot Ulcers
#bpt/endocrinology

PEDIS score, IWDF score

PEDIS score:
1. Perfusion: no PVD -> PVD -> critical limb ischaemia
2. Extent: intact skin -> <1sqcm -> 1-3sqcm -> >3sqcm
3. Depth: intact skin -> superficial -> muscle/tendon -> bone
4. Infection: surface -> local infection -> sepsis
5. Sensation: intact -> lost

Severe DFU/OM needs **urgent** debridement with vascular surgery for source control.

### Overview
Thyroid nodules are graded with the _TIRADS_ score on ultrasound:
- TR1 =  0 points = benign = <1% risk of malignancy
- TR2 = ≤2 points = not suspicious = ~2% risk of malignancy
- TR3 = 3 points = mildly suspicious = ~5% risk of malignancy
- TR4 = 4-6 points = suspicious = ~10% risk of malignancy
- TR5 = ≥7 points = highly suspicious = ~35% risk of malignancy

Components of the TIRADS score (-> = ascending risk) include:
- Compsition: cystic -> solid 
- Echogenicity: anechoic -> hyperechoic -> hypoechoic
- Shape: wide -> tall
- Margin: smooth -> irregular -> extrathyroidal
- Foci: none -> several

The next step is to proceed to FNA, with the decision depending on TIRADS score:
- TR1 = TR2 = no FNA, no follow-up
- TR3:
  - FNA if ≥2.5cm
  - Follow-up if ≥1.5cm
- TR4:
  - FNA if ≥1.5cm
  - Follow-up if ≥1cm
- TR5:
  - FNA if ≥1cm
  - Follow-up if ≥0.5cm

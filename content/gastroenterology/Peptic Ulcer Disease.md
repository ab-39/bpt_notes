# Peptic Ulcer Disease 
#bpt/gastroenterology
- - -
### Overview
If an NSAID-induced bleeding ulcer is successfully clipped, then PPI therapy should be continued for 4-8 weeks based on the size of the ulcer:
- <1 cm -> 4-6 weeks
- 1+ cm -> 6-8 weeks 

PPI optimal timing is half an hour before meals.

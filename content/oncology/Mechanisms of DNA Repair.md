### Overview
Under normal conditions, DNA can be repaired in multiple ways:
| Type of Error                    | Mechanism of Repair        | Key Genes                                                    | Key Cancer Types                |
|----------------------------------|----------------------------|--------------------------------------------------------------|---------------------------------|
| Single-stranded break            | Base excision repair       | _PARP1_<br>_XRCC1_<br>_LIGASE3_                              |                                 |
| Double-stranded break            | Homologous recombination   | _BRCA1/2_<br>_PALB2_<br>_ATM_<br>_CHEK1_<br>_CHEK2_<br>_RAD51_ | Breast<br>Ovarian<br>Pancreatic |
|                                  | Non-homologous end joining | _KU70/80_<br>_DNA-PK_                                        |                                 |
| Bulky adducts                    | Nucleotide excision repair | _ERCC4_<br>_ERCC1_                                           | Xeroderma pigmentosa            |
| Base mismatch/insertion/deletion | Mismatch repair            | _MLH1_<br>_MSH2_                                             | Colorectal                      |
| Base alkylation                  | Direct reversal            | _MGMT_                                                       | Glioma                          |
